# Shelfmates

See what your friends are reading. Everyone keeps a shelf of their favorite 0 to 10 books per category, marks the one they're most excited about, earns badges for keeping it fresh, and shares a card.

Built from Michael's blueprint (Sept 8, 2026). Static site on GitHub Pages, data and logins on Supabase.

- `index.html`, `style.css`, `app.js` — the app
- `config.js` — Supabase project URL and publishable key
- `schema.sql` — run once in Supabase SQL Editor to create the tables and security rules
